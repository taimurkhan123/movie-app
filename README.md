# 🎬 MovieApp

A modern movie discovery web app built with **React**, **Vite**, **Tailwind CSS**, and the **TMDB API**. Browse popular movies, search by title, and explore details in a clean, responsive dark interface.

---

## ✨ Features

- 🎥 **Popular Movies** — Automatically loads trending/popular movies on start
- 🔍 **Search** — Find any movie by title using the TMDB search API
- ⏳ **Loading Skeletons** — Smooth shimmer placeholders while data loads
- ⚠️ **Error Handling** — Friendly error screen with retry option
- 🎭 **Empty States** — Clear feedback when no results are found
- 📱 **Responsive Design** — Works on mobile, tablet, and desktop


---

## 🛠️ Tech Stack

| Tech | Purpose |
|------|---------|
| React | UI library |
| Vite | Build tool & dev server |
| Tailwind CSS | Styling |
| TMDB API | Movie data source |
